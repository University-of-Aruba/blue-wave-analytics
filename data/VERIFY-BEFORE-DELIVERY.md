# Data verification status

Two classes of file sit in this folder. Know which is which before you teach.

## Public, safe to teach

All of these come from public sources and are regenerated by
`Rscript scripts/00_build_teaching_data.R`. Variable definitions and limitations
for the squad file are in `blue_wave_squad_codebook.md`.

- `blue_wave_squad.csv`, the four ABC island national squads, player level, with
  Curaçao's World Cup squad. Scraped from pinned Wikipedia revisions
- `blue_wave_squad.xlsx`, `blue_wave_squad.sav`, the same data in other formats
- `blue_wave_squad_2026-09.csv`, the September 2026 call-up, for Episode 6
- `fifa_global_panel.csv`, `fifa_rankings.csv`, FIFA rank, population, diaspora
- `diaspora_global.csv`, `diaspora_change.csv`, UN DESA migrant stock
- `countries_backup.csv`, offline fallback for the episode 1 live pull

**The squad files no longer drift.** Since 12 September 2026 each snapshot is
pinned to a Wikipedia revision ID, so re-running the build script gives the same
files. If a re-run changes either squad CSV, something upstream moved (a
revision deleted, a page renamed) and the episode figures need checking before
anything is pushed. A new call-up is a new snapshot, added alongside; the World
Cup file stays the one the episodes quote.

## Not verified, do not teach from it yet

`curacao_qualifiers_TEMPLATE.csv` is a shape, not a dataset. It carries the
column names for the CONCACAF qualifying campaign and six empty rows, because
the match-by-match record was not available on disk when the course was built
and nobody should teach from scorelines that were guessed.

Someone has to fill it in from a source they can name: the CONCACAF match
centre, the FFK record, or `worldfootballR`. When it is filled and checked,
save it as `curacao_qualifiers.csv` and note the source and the date here.
Until then the qualifying run is the story the course tells out loud and the
squad data is what learners actually compute on, so nothing breaks if this
file stays empty.
